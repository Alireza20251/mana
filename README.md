# MANA

ساختار اولیه فروشگاه اینترنتی واسطه‌ای مانا.

- فناوری هدف: PHP و MySQL
- ورودی برنامه: `public/index.php`
- فایل نمونه تنظیمات: `.env.example`
- ساختار دیتابیس: `database/schema.sql`

این مرحله فقط اسکلت پوشه‌ها و فایل‌ها را ایجاد می‌کند؛ فایل‌های خالی هنوز منطق اجرایی ندارند.
برای اجرا در XAMPP فعلاً مسیر `http://localhost/mana/public/` را باز کنید.
در محیط نهایی، ریشه وب‌سرور باید روی پوشه `public` تنظیم شود.
